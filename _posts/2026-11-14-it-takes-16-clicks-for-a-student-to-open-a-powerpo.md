# The 16‑Click Dilemma: Why Students Struggle to Open PowerPoint on iPad

> “It takes 16 clicks for a student to open a PowerPoint on an iPad.”  
> — a headline that’s been trending on Twitter, Reddit, and the tech‑savvy corners of education blogs.

If you’ve ever watched a student try to pull up a slide deck on an iPad, you’ve probably seen the same maddening sequence: a dozen taps, a few swipes, a few “Open” buttons, and a final click that finally brings the presentation to life. The frustration isn’t just a minor annoyance—it’s a symptom of a deeper UX problem that’s affecting classrooms worldwide. In this post we’ll unpack the 16‑click journey, dig into why it matters, and explore practical solutions for students, teachers, and developers alike.

## 1. The 16‑Click Journey (Step‑by‑Step)

Below is a typical path a student might take to open a PowerPoint file on an iPad. Count the taps, and you’ll see why the number 16 has become shorthand for “this is too much work.”

| # | Action | App/Location | Why it matters |
|---|--------|--------------|----------------|
| 1 | Tap the **Files** app | Home screen | Entry point |
| 2 | Navigate to **iCloud Drive** or **OneDrive** | Files sidebar | File location |
| 3 | Tap the **folder** containing the PPTX | Folder view | Drill‑down |
| 4 | Tap the **PPTX file** | Preview screen | Open preview |
| 5 | Tap the **Share** icon (three‑dot menu) | Preview toolbar | Access share sheet |
| 6 | Scroll down the share sheet | Share options | Find “Open in… ” |
| 7 | Tap **Open in PowerPoint** | Share sheet | Launch PowerPoint |
| 8 | PowerPoint launches, shows “Open from…” | PowerPoint | Choose source |
| 9 | Tap **Files** again | PowerPoint file picker | Re‑enter file system |
| 10 | Navigate to **iCloud Drive** | File picker | Same folder |
| 11 | Tap the **folder** | File picker | Drill‑down |
| 12 | Tap the **PPTX file** | File picker | Select file |
| 13 | Tap **Open** | File picker | Confirm |
| 14 | PowerPoint loads the deck | PowerPoint | Wait for rendering |
| 15 | Tap **Play** or **Slide Show** | PowerPoint | Start the presentation |
| 16 | Tap **Next** or **Previous
